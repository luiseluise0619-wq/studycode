# CodeRun V2 — Developer Growth Simulator

> **실행하며 배우는 개발 문제집 + 실무 판단 시뮬레이터.** SQL·Python·JS를 실제로 실행해 채점하고, 장애·설계 결정을 시뮬레이션합니다.
> 정직한 포지셔닝: *이 앱만으로 시니어가 되지는 않습니다.* 시니어는 실전(제품을 만들고·배포하고·운영하며)에서 만들어집니다. 이 앱은 그 여정의 **부교재** — 지식 공백을 메우고 실무 판단의 감을 잡는 도구로, 실전과 병행할 때 가치가 있습니다.

빌드·서버·계정 없이 브라우저에서 바로 실행되는 오프라인 PWA. 모든 상태는 `localStorage`에 저장됩니다.

앱은 셸(`index.html`, 516KB · gzip 145KB)과 데이터 청크(`data/*.js`)로 나뉩니다. 첫 화면은 셸만으로 그려지고, 문항·이론은 **고른 트랙의 청크 하나만** 뒤따라 받습니다. 시뮬·진단·프로젝트는 화면이 뜬 뒤 유휴 시간에, SQL 실행 엔진(WASM 852KB)은 SQL 문제를 처음 열 때 받습니다. 첫 로딩은 9.3MB 단일 파일 시절의 10초대에서 **1초대**로 내려갔습니다.

```
입문  →  Junior  →  Mid  →  Senior  →  Staff  →  Principal
```

## 실행

```bash
# 그냥 파일을 브라우저로 열면 됩니다. 서버 불필요.
open index.html          # macOS
```

의존성 0개. 계정 0개. 전부 클라이언트에서 동작합니다.
데이터 청크는 `fetch` 가 아니라 `<script>` 주입으로 불러오므로 `file://` 로 열어도 그대로 동작합니다.
`index.html` 과 `data/` 는 항상 같이 두세요.

### 오프라인

서비스 워커가 셸은 network-first(배포하면 바로 갱신), 데이터 청크는 stale-while-revalidate 로 다룹니다.
한 번 연 트랙은 캐시본으로 즉시 열리고, 콘텐츠를 고쳐 배포하면 캐시 버전을 손대지 않아도 다음 실행에 반영됩니다.

> **정답 정확성 감사(핵심 9트랙 1,901문항)**: Python·SQL·JavaScript·Java·알고리즘·C·C++·Go·React의 모든 choice/input 문항을 독립 검토 에이전트가 재검증 — 특히 코드 출력형 517문항은 **코드를 실제로 함께 보며** 재실행 검증. 결과 99.9% 무결, 실제 결함 1건(텍스트 월 정렬을 오해한 SQL `LAG` 문항)만 제거. (심화 255 + 시니어실전 72는 별도 생성 시 이미 검증)

> **시니어 실전 유닛(+72, 적대적 검증 통과)**: 프로그램의 시니어/스태프 구간을 실제로 뒷받침하도록 3개 핵심 트랙에 최심화 유닛 추가 — 시스템 설계(분산·일관성·quorum·합의·LSM·백프레셔), 백엔드(트랜잭션 격리 이상현상·MVCC·인덱스 sargability·멱등성·전달 의미론), 앱보안(XSS/CSRF/SQLi/SSRF 올바른 방어·JWT/OAuth 함정·암호 모드). 생성 후 별도 검토 에이전트가 정답을 독립 재검증 — 72문항 전부 무결(0 flagged).

> 직접 코딩(테스트 통과형): 함수를 구현하면 여러 테스트 케이스로 자동 채점(Implementation Score: 정확성·엣지·성능·품질) — 코딩 실습·알고리즘 트랙.
> 직접 SQL: `sql.js`(SQLite WASM 인라인)로 브라우저에서 실제 쿼리를 실행해 결과셋을 정답과 비교 채점 — SQL 트랙.
> 직접 Python: `Pyodide`로 브라우저에서 실제 파이썬을 실행해 함수 구현을 테스트 케이스로 채점(Implementation Score) — Python 트랙(직접 코딩 유닛). 배포(온라인)에서 동작, 오프라인은 안내 후 폴백.
> 에디터: 코드/SQL/Python 편집기는 **Monaco(VS Code 엔진)** 로 문법 강조·자동완성 제공(CDN 로드). 로컬·차단 환경에선 자동으로 일반 textarea로 폴백.
> **AI 멘토(V5) — 막히면 바로 물어보기**: 문제 화면의 `🙋 모르겠어요` 버튼으로 **모든 유형**(선택형·단답·리뷰·로그·코드·SQL·Python)에서 질문할 수 있습니다.
> 풀기 **전**에는 시스템 프롬프트가 정답을 잠급니다 — 힌트·개념 설명·접근법만 주고, "그냥 답 알려줘" 는 거절합니다.
> 답을 낸 **뒤**에는 잠금이 풀려 정답 근거·내가 왜 틀렸는지·실무에서 어떻게 드러나는지를 설명합니다. 앞선 질문을 기억해 이어서 물어볼 수 있고, 코딩·SQL은 제출 코드에 대한 시니어 리뷰도 그대로 받습니다.
