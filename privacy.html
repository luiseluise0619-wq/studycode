코드런 · 데이터 안내

내 공부 기록은
어디에 남을까요?

현재 앱이 저장하는 내용과 외부로 보내는 내용을 설명해요. 기준일은 2026년 10월 8일이에요.

진도와 코드는 지금 쓰는 브라우저에 남아요

완료한 레슨, 정답과 오답, 복습 일정, 학습 설정, 작성한 코드와 프로젝트 메모를 브라우저의 저장 공간에 보관해요. 기본 학습에는 계정이 필요 없고, 앱이 이 기록을 학습 서버에 자동으로 올리지 않아요. 다른 기기와 자동으로 동기화하지도 않아요.

브라우저 데이터를 지우거나 다른 주소에서 앱을 열면 기존 기록이 보이지 않을 수 있어요. 오래 보관할 기록은 홈의 백업으로 받아 두세요.

백업 파일에는 학습 기록이 들어 있어요

백업에는 작성한 코드와 메모도 들어가요. 새로 받는 백업에는 AI API 키와 서버 연결 코드를 넣지 않아요. 예전 버전에서 받은 백업에는 키가 있을 수 있으니 공유하기 전에 확인해 주세요. 복원은 확인창을 거쳐 현재 기록을 바꿔요.

AI를 요청할 때만 질문과 코드를 보내요

AI 도움은 선택 사항이에요. API 키를 연결하면 AI 도움 버튼을 누를 때 현재 질문, 관련 설명, 입력한 답이나 코드를 선택한 제공자(Google, OpenAI, Anthropic)에게 보내요. 서버 연결 코드를 쓰면 앱 서버를 거쳐 Google에 보내요. 제공자의 보관·사용 방식은 각 제공자의 정책을 따라요.

입력한 API 키와 서버 연결 코드는 이 브라우저에 저장돼요. 공유 기기에서는 AI 설정에서 키나 연결 코드를 비우고 저장해 주세요. 코드에 비밀번호나 개인정보를 넣지 않는 편이 좋아요. 질문을 복사하는 기능은 외부 AI에 자동으로 보내지 않아요.

실행 도구와 접속 기록

기본 JavaScript·SQL·화면 실습은 브라우저에서 실행해요. Python 실행기를 처음 준비할 때와 코드 편집기를 불러올 때는 외부 CDN에 파일을 요청할 수 있어요. 별도 실행 서버를 연결한 언어에서는 실행 버튼을 누르면 코드와 검사 자료를 설정한 서버로 보내요.

이 앱에는 광고나 방문 분석 도구를 넣지 않았어요. 웹사이트 운영에 사용하는 호스팅 서비스와 외부 API·CDN은 요청을 처리하며 IP 주소 등의 접속 기록을 남길 수 있어요.

기록을 지우려면

홈의 전체 초기화는 확인 후 앱의 학습 기록과 연결 설정을 지워요. 브라우저의 사이트 데이터 삭제로 저장 공간과 오프라인 캐시도 지울 수 있어요. 이미 내려받은 백업 파일은 직접 지워 주세요.

앱 동작에 문제가 있으면 문제 제보에 남겨 주세요. 공개 게시판에는 API 키나 개인 기록을 올리지 마세요.
